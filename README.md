# ارائه پردیس نوآوری گرا

ارائهٔ ۱۵ اسلایدی (HTML + CSS + JS خالص، بدون build و بدون وابستگی) بر پایهٔ بروشور «گرا — سازمان فردا، از ایده تا اجرا».

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا از یک سرور ساده استفاده کنید:

```bash
npx serve .
```

## انتشار روی Vercel
1. این پوشه را روی GitHub بگذارید.
2. در Vercel: **Add New → Project** و ریپو را Import کنید.
3. Framework Preset را **Other** بگذارید. Build Command و Output Directory را خالی بگذارید و Deploy بزنید.

## کلیدهای ناوبری
| عمل | کلید / حرکت |
|---|---|
| اسلاید بعد | `←` ، `Space` ، `PageDown` ، کشیدن انگشت به راست |
| اسلاید قبل | `→` ، `PageUp` ، کشیدن انگشت به چپ |
| اول / آخر | `Home` / `End` |
| تمام‌صفحه | `F` |
| پرش مستقیم | آدرس `#۷` یا کلیک روی خدمات در اسلاید ۳ |

## ساختار
- `index.html` — محتوای همهٔ اسلایدها (متن‌ها اینجا ویرایش می‌شوند)
- `style.css` — طراحی؛ رنگ‌ها در متغیرهای `:root` بالای فایل
- `script.js` — ناوبری، مقیاس‌دهی صحنه، شمارندهٔ آمار، یادداشت
- `assets/` — عکس‌ها و لوگوها (برش‌خورده از PDF اصلی)
- `fonts/` — Dana (فنَپ) و Source Serif 4 (مجوز OFL)

## نکته
یادداشت اسلاید ۱۴ فقط در مرورگر خود کاربر (localStorage) ذخیره می‌شود.
